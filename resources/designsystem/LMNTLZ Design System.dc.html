Electron · Steam · Browser Vite · React · Tailwind Desktop only · 1280×720 min
Single source of truth

Foundations, components, and the states nobody remembers.

A pointer-driven desktop kit for a server-authoritative game. Hover is load-bearing. Every action is in flight for a moment. The app boots empty, and it goes offline on purpose — so skeletons, pending states, reconnect, and maintenance are components here, not footnotes.

POINTER, NOT TOUCH
No touch minimums. Focus rings mandatory — full keyboard nav.
SERVER RESOLVES COMBAT
Every control has a pending state between click and truth.
NO SSR
Skeletons and empty states ship with every data surface.
OWNS ITS WINDOW
Custom title bar in Electron; browser build defers to chrome.

Connection & system states

Guaranteed to be seen, usually designed in launch week. The rule: never blame the player, always say what happened to their progress. Connection loss mid-battle is a component, not a toast.

IN-FLIGHT INDICATOR · TOP BAR
Resolving turn 7…
38ms
Sits in the top bar so it never covers the battlefield. Latency read is always visible in-battle — players blame the server less when they can see it.
RECONNECTING
Reconnecting · attempt 2 of 5
Controls lock but stay visible — nothing greys out, so the board is still readable while the socket retries with backoff.

# LMNTLZ hero emblems

27 flat-vector hero emblems + one overview sheet, built to `resources/icons/hero-vector-icons.md`.

- One file per hero, named by slug (`dark-nyxara.svg`), 128×128 viewBox, transparent artboard, no fonts.
- Each emblem: shared hex-medallion frame in the House core colour, inner darkening in the deep step, 4px accent rim, a flat geometric motif glyph, and the type sigil in a fixed bottom-right corner.
- Palette is the nine type tokens plus one shared ink light (#F2EDDD) and dark (#14121F) — nothing off-palette.
- Every emblem's root group carries `id="<slug>"`, so icons can be lifted into a sprite sheet.
- `00-overview-3x9.svg` — 3 heroes per row × 9 type rows, dark ground, labelled.

Scale freely; stroke weights are uniform and hold from 24px to poster size.
